# Examples and Tutorials
EarthScope is in the process of building out a resource library of examples, tutorials, and educational resources to help you adapt your existing workflows to the cloud and to grow your scientific computing skills. Please explore these resources and we appreciate your patience as we gradually develop this material.

These resources range from foundational training in using GeoLab to standalone examples and more in-depth courses focused on specific scientific tools and workflows.

## Cloud Foundations
This free, asynchronous online course is designed to orient you to the GeoLab platform and the whys of computing in the cloud. In 2–3 hours, it will walk you through the GeoLab login, get you started on your first project, and ground you in the fundamentals of working in a JupyterHub. 

Cloud Foundations is a good starting point if you are new to GeoLab or want to strengthen the computing skills used across other GeoLab learning resources.

Log in to our [online learning platform]({{ cloud_foundations }}) with your EarthScope account and select Cloud Foundations in our Enrollment Hub.

## GeoLab Tutorials
Instructional Jupyter notebooks for working with EarthScope data and scientific workflows in the cloud are available in [GeoLab Tutorials]({{ geolab_tutorials }}).

These instructional notebooks use authentic seismic, geodetic, and computational tasks to build practical research-computing skills in GeoLab. Learning pathways progress from accessing and exploring data to executing, adapting, and eventually scaling scientific workflows. The instructional notebooks are designed to build on the operational skills introduced in Cloud Foundations and can be completed independently based on the pathway most relevant to your work. 

We recommend you use [`git`](./using_git.md) to clone or fork this entire repository into your workspace, so you have your own copy of the notebook files to work on. 

## GeoLab Learning Hub
Standalone example notebooks and projects are located in the [GeoLab Learning Hub]({{ learning_hub }}), a GitHub repository highlighting scientific workflows, applications, and reusable code in GeoLab.

These materials are designed to be explored independently and may demonstrate a specific scientific use case, technique, workflow, or code pattern rather than provide a structured learning pathway. 

## Technical Courses and Workshops
EarthScope offers a number of in-depth technical courses and workshops on specific topics in geophysics. Many of these operate in GeoLab and teach scientific computing concepts. These offerings provide a more structured learning experience around a particular scientific method, software package, or workflow.

Check out the offerings and register [here]({{ course_offerings }}).
