# Accessing GeoLab

Access to GeoLab requires a free [EarthScope User Account.]( {{ user_accounts }})

Navigate to the [GeoLab Home Page]( {{ geolab_home }} ) and click the 'Launch GeoLab' button. 

When the login screen appears, use the same method that you used to register for your EarthScope User account (email & password, OR "Continue with..."). Once your identity has been confirmed, you will be taken to the [Server Options](./server_launch.md) screen.
